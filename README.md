# 航空温控货物运输放行与温度偏差调查平台

基于React、Ant Design、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。无需后端，浏览器持久化演示数据。

## 功能

- 温控运输任务列表、关键词和状态筛选。
- 航段时间轴、温度曲线缩放、原始时间点定位与超限标记。
- 设备离线缓存补传：机场当地时间按时区统一为UTC时刻，同时刻保留设备读数、人工值另存待复核，重复补传不重复建点，导入失败整段回滚并可从完整航段重试。
- 设备记录更新后超限窗口自动重算，未关闭偏差标记重新确认；待复核期间禁止放行。
- 温度曲线、设备报告、包装确认和交接签字证据的版本管理。
- 温度超限自动/人工偏差、原因调查、影响评估和放行复核。
- 多角色签收、未核验证据与未关闭偏差放行拦截、完整报告导出；任务详情与偏差工作台显示同一放行状态。

端口为`18465`。

```bash
npm install
npm run build
npm run dev
```
